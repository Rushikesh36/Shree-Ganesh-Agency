# 🧾 Shree Ganesh Agency – Client & Billing Management System

## 🏢 About the Project
**Shree Ganesh Agency** is a custom-built web application developed for **Shree Ganesh Agency**, owned and operated by my father.  
The goal of this project is to **digitize client, billing, and payment tracking**, making day-to-day business operations simpler, faster, and more reliable.

The system replaces manual bookkeeping with a secure, structured, and easy-to-use digital solution.

---

## ✨ Key Features

### 👥 Client Management
- Create, read, update, and delete client records
- Maintain complete client details in one place

### 🧾 Billing Management
- Create bills corresponding to a specific client
- View and manage all bills linked to each client
- Clear mapping between clients and their bills

### 💰 Payment Tracking
- Add payment details against individual bills
- Track:
  - Total bill amount
  - Payments received
  - Outstanding balance
- Helps monitor pending dues and completed payments accurately

### 🔐 Authentication
- Secure login using **Google OAuth**
- Ensures only authorized access to business data

### 🖨 PDF Export & Printing
- **Print / Download PDF** functionality
- Generates a PDF containing:
  - Client details
  - Bill information
  - Complete payment history for that client
- Useful for records, audits, and sharing with clients
